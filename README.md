# go-rrt：RRT* 渐近最优路径规划（Go 标准库 + 原生 HTML/JS 回放）

在含障碍物的二维空间中实现 **RRT\*（Rapidly-exploring Random Tree Star）**：
随机采样增量建树，每次插入新节点后在邻域内执行**选父 + 反向重布线（rewire）**，
路径代价随采样次数单调不增、渐近收敛到最优。全部仅用 Go 标准库；
可视化报告是**单一静态 HTML 文件**（数据与逻辑内嵌，无框架、无第三方库、无需启动服务）。

## 目录结构

```
geometry.go                      向量/矩形、闭集碰撞检测（Liang–Barsky 线段裁剪）
rrtstar.go                       RRT* 核心：采样/选父/反向重布线/子树代价传播/回升检测
rrtstar_test.go                  自动化测试（边界碰撞、重布线、单调不增、大采样）
cmd/rrtstar-demo/main.go         demo：运行一次规划并生成 report.html
cmd/rrtstar-demo/report.go       内嵌的单文件 HTML/CSS/JS 回放器模板
report.html                      生成产物（已在 .gitignore 中）
```

## 快速开始

```bash
# 运行全部测试
go test ./... -v

# 生成单文件可视化报告（默认 2500 次采样、种子 20260928）
go run ./cmd/rrtstar-demo -seed 20260928 -iter 2500 -out report.html
# 然后直接用浏览器打开 report.html，无需任何服务器
```

页面支持：逐步/自动播放树的生长、直接跳转到上一/下一个**重布线事件**、
高亮每次重布线的节点（旧边虚线、新父边粗紫线、代价变化标签）、邻域半径开关、
代价收敛曲线（hover 查看逐迭代数值）、深浅色主题、URL hash 定位
（`#frame=376`、`#final`、`#play`、可附加 `&light` / `&dark`）。

## 一、重布线（rewire）判据

每个节点保存根到该节点的累计代价 `cost(n) = cost(parent(n)) + |parent(n)−n|`（欧氏距离）。
新节点 `x_new` 插入分两个阶段：

1. **选父（chooseParent）**：在邻域 `B(x_new, r)` 内所有与 `x_new` 无碰撞直连的
   已有节点中，选 `cost(x) + |x−x_new|` 最小者作为父节点（最近节点仅为兜底候选）。
2. **反向重布线（rewireNeighbors）**：对邻域内每个**已有**节点 `x`，当且仅当

   ```
   cost(x_new) + |x_new−x| < cost(x) − ε    且    线段 x_new—x 无碰撞
   ```

   才把 `x` 改接到 `x_new`。

判据方向是“**已有节点 x 能否借新节点降低自己的代价**”——这是最容易写反的地方：
反向写成 `cost(x) + ... < cost(x_new)` 检查的是新节点能否挂到 x 下（那是选父阶段
已经做过的事），会漏掉所有真正的邻域改进，得到一棵次优但表面合法的树。

改接后代价差 `Δ = newCost − oldCost`（必为负）必须沿 `x` 的**整棵子树**传播
（`rewireNode` 用显式栈完成），否则后代的 `cost` 会与真实路径代价脱节，
进而污染后续所有选父/重布线判据。测试 `TestRewireStrictlyDecreasesCosts`
在规划结束后对全树复核 `cost(n) == cost(parent(n)) + |parent(n)−n|` 不变量，
专门捕捉“只改节点自身、不传播子树”这类错误。

严格改进容差 `ε`（默认 `1e-9`）：平局不换父，保证固定种子下结果确定、可复现。
邻域半径采用 Karaman–Frazzoli 收缩式 `r = clamp(γ·sqrt(ln n / n), rmin, rmax)`。

改接安全性：被重接的邻域节点 `x` 若是新节点祖先链上的节点，由选父阶段的
最小性 `bestCost ≤ cost(x) + |x−x_new|` 可推出候选代价 `≥ cost(x)`，
严格改进判据必然失败，因此结构上不可能成环。

## 二、碰撞检测规则（边界一致）

障碍物是**轴对齐闭矩形**，即边界（四条边、四个角点）本身属于障碍物。
线段相交采用 **Liang–Barsky 线性裁剪**：把线段写成 `a + t(b−a), t∈[0,1]`，
求它同时落在 x、y 两个闭区间内的 t 区间，与 `[0,1]` 交集非空即碰撞，
交集退化为单点也算。统一规则如下且**与线段方向无关、重复调用一致**：

| 几何情形 | 判定 |
|---|---|
| 线段穿过障碍物内部 | 碰撞 |
| 端点恰好落在边 / 角点上 | **碰撞** |
| 线段沿某条边界重合行走 | **碰撞** |
| 斜向恰好穿过一个角点（单点相切） | **碰撞** |
| 零长度线段（点）落在边界/内部 | **碰撞** |
| 与边界距离超出容差（1e-9）的外侧平行/掠过 | 不碰撞 |

起点、目标若落在障碍物边界上，配置校验直接报错（闭集语义不允许在配置层绕过）。
对应测试：`TestSegmentCollisionBoundaryCases`（19 个边界用例）、
`TestCollisionSymmetricAndRepeated`（正反向 5 次重复结论一致、点判定与
零长度线段判定一致）。

## 三、渐近最优性验证与代价回升检测

固定随机种子（`math/rand` 的 `rand.NewSource(seed)`，最近节点平局取较小 id），
逐迭代记录当前最优目标节点代价 `J_i`。正确的 RRT* 结构保证 `J_{i+1} ≤ J_i`：
节点只增不删，任何边变化都以严格降低代价为前提且整树一致更新。

规划器内置**回升检测器**：每次迭代结束后若 `J_i > J_{i-1} + ε`，
记录一条 `Regression{Iteration, Prev, Cur}`。报告页顶部徽章在回升数非 0 时
变红告警，代价收敛曲线上也能逐迭代核对（另附数据表）。

自动化覆盖（`go test ./...`）：

- `TestBestCostMonotonicNonIncreasing`：4 个固定种子 × 1500 次，
  帧序列独立复核 `J_i` 单调不增，且 `Regressions` 为空；
- `TestRewireStrictlyDecreasesCosts`：每次重布线都严格降代价、父节点确实改变，
  规划后全树代价递推不变量成立；
- `TestNeighborCostReduction`：确认存在“邻域内已有节点经新节点改接后代价降低”
  的事件，且降低方向正确；
- `TestLargeSampleNoRegression`：**6000 次大采样**下零代价回升；
- `TestConvergenceImprovesWithMoreSamples`：同种子 3000 次结果不劣于 500 次；
- `TestResultPathIsCollisionFree`：输出路径逐段无碰撞且连通起终点；
- `TestDeterministicFixedSeed`：同种子两次运行逐位一致；
- 碰撞边界用例与起/终点落边界的配置拒绝测试。

> 说明：渐近最优是概率意义上的（n→∞ 依概率收敛到最优）。有限次数下不同种子
> 的中间轨迹不同，但**每个种子自身**的 `J_i` 必须单调不增——本项目测试的正是
> 这一可机器检验的结构性质，并通过大采样次数（6000）观察持续下降/趋平的收敛行为。

固定 demo 场景、种子 42 的一次实测（代价回升均为 0），可直观看到随采样预算
增加最优代价持续下降：

| 采样上限 | 节点数 | 重布线事件 | 最优代价 |
|---|---|---|---|
| 800  | 510  | 109  | 123.7033 |
| 1500 | 1071 | 551  | 122.2693 |
| 2500 | 1885 | 1729 | 112.5884 |
| 6000 | 4762 | 6813 | **98.2905** |

## 四、报告文件的数据格式（回放原理）

`report.html` 内嵌一段 `application/json`：

- `nodes`：所有节点坐标与出生迭代；
- `frames`：每次采样一个事件帧，含采样点、邻域半径、是否被拒、
  以及 `changes` 变更序列（`add` 新增 / `rewire` 改接，附旧/新父节点与旧/新代价）。

回放器不依赖任何预置树快照，而是**从空树按帧顺序累计 `changes` 重建任意时刻的树**
（重放时对子树做同样的代价传播），因此拖动进度条双向跳转都与 Go 端状态严格一致。
